# 离屏休息与桌面伙伴

本轮目标是减少用户完成一次休息需要的注意力，让角色有可辨认的个性，并能从正常工作距离看清提醒。功能跑通只是起点；用真实打包窗口检查可读性、操作次数、动作和失败路径。

## 一眼读完，然后离开屏幕

主进程每次选择一个建议，避开近期重复。去掉光球追踪、模式切换、开始按钮和完成打卡；一条大字建议在整次休息保持稳定。音效开启时给出开始与结束提示，不要求看倒计时。有事仍可稍后或跳过，键盘 Escape 可稍后；取消单字母 S 快捷键，避免弹窗夺焦后键入字母误跳过。

采用看远处、自然眨眼、闭目自然呼吸和起身走动的轻量建议，不要求按屏幕做对焦训练、屏息数拍、按压眼睛或连续阅读步骤。离开屏幕看远处的方向参考 [美国国家眼科研究所的屏幕休息建议](https://www.nei.nih.gov/eye-health-information/healthy-vision/how-eyes-work/keep-your-eyes-healthy)。应用提示不判断用户是否实际完成动作。

primary/emergency 真正显示后才开始计时。主进程用 SchedulerKernel 在结束后保留 2.5 秒反馈，再自动记录和收起；renderer 只展示状态。通知或全部表面失败不会把看不见的休息算作完成。番茄钟仍由用户手动继续。

## 角色应有不同的样子和动作

- 火力奋斗猫：保留用户原作的四个 GIF，火焰敲键盘是待机，挥爪是互动，打哈欠是预告，睡觉是休息。原文件内置，独立于 data 目录。
- 泡泡水獭：像素阶梯轮廓、暖棕色和水面，抱贝壳，互动时吹泡泡。
- 星际企鹅：像素太空服轮廓、头盔和冷色点缀，互动时接流星。
- 像素橘猫：保留复古风格与四套衣服，作为可选风格。
- 我的动图：素材存在时才出现，空目录不拿默认猫冒充用户角色。

像素轮廓在高 DPI 下保持清晰；用户原作保持原来画风。关闭动态、页面隐藏与系统减少动态效果都停止美术帧，GIF 用静态快照。角色没有解锁或养成要求。

## 正常距离下的大小

提醒依据当前显示器 workArea 的逻辑尺寸增长，标准上限 1440×960 DIP，字号随可用宽度增长。阅读大小设置同时作用于提醒和工作台，桌宠大小独立。Windows DPI 已由 Electron 换算，不重复乘设备缩放比例；小屏优先保留文字与稍后/跳过出口，装饰角色可以隐藏。

工作台用局部 CSS zoom 和补偿后的滚动高度扩大，避免 Electron 同源页面 zoom 传播到桌宠、气泡。测试用真实运行窗口和模拟内容视口验证 480×440 与大屏布局；多块物理显示器、观看距离和不同人的舒适度仍需实际体验，不将模拟视口写成硬件验收。

## 工作台层级与动画

沿用暖中性色、语义色和已有角色。工作台把页面标题、日期和状态放在同一阅读起点；队列标题不再重复日期。无步骤的任务将添加步骤入口放在任务行内，已有步骤仍保持直接可操作，长标题和步骤可以换行。设置页保留分区和控件；分区导航只滚动而不改变受信任的窗口路由，锚点暂留 76px 上边距，容纳固定标题栏并留出间隔（工作假设，需随标题栏尺寸复验）。休息页仍以一眼读完的建议和随时可用的出口为主，空间不足时优先保留文字与操作。

基础间距、圆角、主题和 140/220/360ms 交互时间沿用 `tokens.css` 与 `theme.css`（项目约定）。队列和快捷控件以相同的中性表面与边界区分状态；状态不单靠颜色表达。伙伴空状态跟随当前选择，GIF 保留原文件。其他内置角色以整格像素和帧切换呈现轻微待机与互动，避免插值模糊轮廓。高频任务行悬停只改变表面与边界，不移动行；提醒进入采用一次性 220ms 轻微位移和淡入（工作假设），不延迟操作。

系统减少动态效果时，完成反馈的元素和伪元素均不动画，任务定位也不平滑滚动；桌宠动效关闭、窗口隐藏或系统减少动态效果时，美术帧停止，休息页装饰也在窗口隐藏时停止。验证时应覆盖浅色/深色、普通/放大阅读尺寸、窄内容区、任务展开、空状态和休息窗口；截图比较只能支持对应视口和状态下的判断，物理显示器体验仍需实际使用确认。

## 验收入口

类型、完整测试、lint、package；`smoke-simple-experience.mjs` 检查无点击的开始/结束、专注暂停、完成记录及任务/拖动；`smoke-pet-ui.mjs` 保留像素衣橱回归；`smoke-companion-experience.mjs` 检查干净安装原作、独立角色、键盘选择、GIF 静止、阅读大小与窄窗口。三者使用隔离数据，按 1 / 1.25 / 1.5 设备缩放运行，另测 emergency 与 pet failure。

2026-10-10 本地打包验收：typecheck、529 项测试、产品/UI/build 契约和 NSIS/portable 打包通过；上述三个实窗脚本在 100%、125%、150% 参数下通过，应急与桌宠失败路径通过。应急提醒另外验证了 480×440 视口与 1.5 倍阅读大小的组合。

截图和度量保存在 `artifacts/polish/simple-*`、`artifacts/pet-ui/*` 与 `artifacts/companion-ui/*`，均为生成物。原作四段 GIF 的 SHA-256 与本地原文件逐一相同。1440×960 内容视口中默认标题约 63 px，1.5 倍阅读大小约 95 px；480×440 中分别为 28 px 与 42 px，文字没有覆盖操作出口。设备缩放参数和内容视口模拟不代替物理显示器拔插、跨屏 DPI 或观看距离验收。
