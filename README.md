# EyeProtect

EyeProtect 是一个 Windows 桌面护眼桌宠提醒工具。它常驻后台托盘，桌面上保留一个透明小人物；到点后小人物会放大、置顶并播放夸张动作，提醒你放松眼睛或站起来走走。

## 功能

- 护眼提醒和走动提醒分别计时。
- 提醒间隔、稍后提醒时间、桌宠缩放都可以在设置窗口调整。
- 提醒时支持完成、稍后、跳过。
- 空闲时双击桌宠可直接打开设置；提醒时双击动画可在倒计时结束后快速完成。
- 护眼和走动提醒在 60 秒内同时到期时会合并成一次提醒。
- 暂停会冻结剩余时间：恢复提醒后从剩余时间继续，也可以「重新开始计时」。
- 托盘菜单随状态实时更新（下次提醒时间、暂停/恢复、待办数量），休眠唤醒和锁屏解锁后会结合系统空闲时间重新安排提醒，不会连续补弹。
- 配置保存到 `data/settings.json`，提醒运行状态（下次提醒时间、暂停等）保存到 `data/runtime-state.json`，重启后继续原有计划，适合免安装便携使用。

## 架构

- 桌宠窗口是唯一常驻窗口（约 160px，透明可拖动）；提醒触发时创建独立的提醒窗口并在结束后销毁，提醒图片缓存随之释放。
- 待办气泡按需创建，隐藏一段时间后自动销毁；设置、面板窗口关闭即销毁。
- 调度器只在截止时间（下次提醒、暂停结束等）唤醒，而不是每秒轮询。

```powershell
npm run typecheck

npm run build
```

## 打包

```powershell
npm run package
```

打包产物默认在 `release/` 下生成 Windows x64 便携 exe。第一版仅面向 Windows 10/11 x64。
