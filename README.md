# EyeProtect

EyeProtect 是一个 Windows 桌面护眼桌宠提醒工具。它常驻后台托盘，桌面上保留一个透明青蛙桌宠；到点后通过气泡或独立提醒卡片，引导你放松眼睛或站起来走走。

## 功能

- 护眼提醒和走动提醒分别计时。
- 提供温和、引导、专注三档提醒模式：温和模式使用桌宠气泡，引导模式给出可随时完成的休息建议，专注模式暗化桌面并等待建议时长。
- 提醒间隔、提前预告、稍后提醒时间、桌宠缩放都可以在设置窗口调整；正式提醒前可选择现在休息、延后 2 分钟或按原计划。
- 提醒时支持完成、稍后、跳过。
- 每次提醒会给出一个具体的微休息动作和当前步骤；组合提醒分别提供护眼与走动动作。
- 待办可标记为「下次走动时提醒」，走动或组合提醒会带上最高优先级的一项，并可在提醒卡片中直接完成。
- 完成、稍后、跳过和自然离开会形成仅保存在本机的健康趋势；设置页提供周报、CSV/JSON 导出、30/90 天保留和一键清除。
- 桌宠会根据当日休息情况呈现平静、期待、开心、疲惫和睡眠状态，并按完成次数临时解锁水杯、眼镜或叶子配饰。
- 可设置跨夜固定免打扰时段与前台应用白名单。前台应用只在提醒真正到期时读取一次进程名，不读取窗口标题；常见会议应用改用系统轻提示，连续自动推迟 3 次后仍会显示提醒。
- 可选择本地自适应节奏：样本充足且稍后/跳过过半时，下一周期最多放宽基准间隔 20%；界面会解释原因，关闭后立即恢复基准。
- 可启用全局快捷键：立即休息 `Ctrl+Alt+B`、暂停/恢复 `Ctrl+Alt+P`、快速添加待办 `Ctrl+Alt+A`、打开待办 `Ctrl+Alt+T`、隐藏/显示桌宠 `Ctrl+Alt+H`；设置页会显示组合键冲突，也可整体关闭。
- 设置页可导出或导入包含设置、待办、闹钟和提醒历史的完整 JSON 备份，也可恢复默认、打开数据目录；损坏配置会自动隔离并显示恢复入口。
- 桌宠位置按当前显示器拓扑分别保存：显示器断开时迁移到仍可用的屏幕，原布局重连后恢复对应位置。
- 空闲时双击桌宠可直接打开设置；温和提醒时双击桌宠可完成当前休息，提醒卡片在允许完成后也支持双击。
- 护眼和走动提醒在 60 秒内同时到期时会合并成一次提醒。
- 暂停会冻结剩余时间：恢复提醒后从剩余时间继续，也可以「重新开始计时」。
- 托盘菜单随状态实时更新（下次提醒时间、暂停/恢复、待办数量），设置页和托盘提供暂停 10 分钟、会议 30 分钟、到下一整点、今日停用和自定义时间；休眠唤醒和锁屏解锁后会结合系统空闲时间重新安排提醒，不会连续补弹。
- 配置保存到 `data/settings.json`，提醒运行状态保存到 `data/runtime-state.json`，本地行为历史保存到 `data/reminder-history.json`；损坏文件会隔离备份，重启后继续原有计划，适合免安装便携使用。

## 架构

- 桌宠窗口是唯一常驻窗口（约 160px，透明可拖动）；提醒触发时创建独立的提醒窗口并在结束后销毁，提醒图片缓存随之释放。
- 待办气泡按需创建，隐藏一段时间后自动销毁；设置、面板窗口关闭即销毁。
- 调度器只在截止时间（下次提醒、暂停结束等）唤醒，而不是每秒轮询；前台场景检测同样只在真实提醒到期时执行。

## 开发

```powershell
npm install
npm run dev
```

## 验证

```powershell
npm run typecheck
npm test
npm run build
npm run smoke:experience -- 9333
```

`smoke:experience` 用于已通过 `--remote-debugging-port=9333` 启动的隔离测试实例；日常提交前运行前三项即可。

## 打包

```powershell
npm run package
```

打包产物默认在 `release/` 下生成 Windows x64 便携 exe。第一版仅面向 Windows 10/11 x64。
